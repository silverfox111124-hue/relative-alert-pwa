# 相対アラーム PWA (v0.3)

Android Chrome 向けの軽量 PWA 試作品です。基準時刻から相対時刻を計算し、ページを開いている間に音つきアラームを鳴らします。サーバー不要・ログイン不要・外部ライブラリなしで動作します。

## v0.3 機能

- 基準時刻入力 (`HH:mm`。例: `08:20`, `9:05`)
- プリセット選択
- `offsetMinutes` による相対時刻計算（マイナス / 0 / プラス対応）
- 計算結果プレビュー（時刻順）
- プレビューしたアラームの一括セット
- 10秒 / 20秒 / 30秒の音つきテストアラーム
- アラーム音の選択（内蔵音3種類 / スマホ内の音声ファイル）
- アラーム音の有効化、鳴り続ける音の停止
- セット中アラーム一覧表示
- すべてキャンセル
- `localStorage` 保存（基準時刻 / プリセット / 選択中の音）
- 選択した音声ファイルの IndexedDB 保存
- PWA 基本構成（manifest + service worker + SVG アイコン）

## 使い方

1. `index.html` を Android Chrome で開く（ローカルサーバー推奨）。
2. 必要に応じてアラーム音を選ぶ。
3. スマホ内の音を使う場合は「スマホ内の音を選ぶ」から音声ファイルを選択。
4. 「音を有効化」を押して、ブラウザで音が鳴る状態にする。
5. 基準時刻を入力し、プリセットを選択。
6. 「計算してプレビュー」で一覧確認。
7. 「プレビューをアラームセット」で音つきアラームを予約。
8. アラームが鳴ったら「鳴っている音を止める」で停止。

## 動作確認方法

### PC (簡易)

```bash
python3 -m http.server 8080
```

`http://localhost:8080` を開いて UI、計算、音の選択、10秒テストアラームを確認。

### Android Chrome

1. 同一ネットワーク上の端末からページを開く。
2. Chrome メニューから「ホーム画面に追加」。
3. 追加後に起動し、「音を有効化」を押す。
4. 必要なら「スマホ内の音を選ぶ」で音声ファイルを選択。
5. 10秒テストアラームを実行し、選択した音が鳴り続けることと停止できることを確認。
6. 必要に応じてプレビューから実アラームをセット。

## 音つきアラームの制約（重要）

- Web Audio は、ユーザー操作後でないと再生できないことがあります。最初に必ず「音を有効化」を押してください。
- ブラウザPWAから Android の標準アラーム音一覧を直接開けるとは限りません。代わりに、ファイル選択でスマホ内の音声ファイルを選べるようにしています。
- 選択した音声ファイルはブラウザ内の IndexedDB に保存します。ブラウザデータを削除すると消えます。
- PWA / ブラウザのタイマーは、Android / Chrome / 省電力設定 / バックグラウンド制限に左右されます。
- ページやPWAが終了している間、OS標準アラームのように確実に鳴る保証はありません。
- v0.3 は「ページを開いている間に選択した音を鳴らし続ける」試作品です。
- 長時間後の厳密な起床アラームや絶対に逃せない予定には、端末標準の時計アプリ等を併用してください。
